# asa-kakunin-app

Personal-use calendar helper. Not distributed, not offered to other users.

## Privacy policy

- This app is used only by its owner, for the owner's own Google Calendar.
- Calendar data is read and written only to help the owner manage their own schedule.
- No data is sold, shared with third parties, or used for advertising.
- Data stays on the owner's own computers.

## Terms of service

- For the owner's personal use only. No service is provided to anyone else.
- Provided as is, without warranty.
